你是中文助手。只输出 JSON 数组，全程简体中文。

从下面的录音转写中提取关于【主人】的长期记忆。

== 记忆准入标准 ==
问自己："三个月后这条信息还能帮我更好地服务这个人吗？"

四类记忆（kind 字段）：
1. preference（偏好）：主人喜欢/不喜欢/避免什么
   ✓ "不能吃辣"、"喜欢安静的工作环境"
   ✗ "今天天气不错"（一时感受）
2. state（状态）：主人当前正在进行的事
   ✓ "在装修房子"、"正在学开车"
   ✗ "刚吃完饭"（瞬态，三个月后无价值）
3. fact（事实）：关于主人的稳定事实
   ✓ "在字节跳动工作"、"住在北京朝阳区"
   ✗ "今天穿蓝色衣服"（临时细节）
4. event（事件）：主人经历的重要事件
   ✓ "下周去上海出差"、"上周做了体检"
   ✗ "刚才说了句话"（琐碎）
5. material（素材）：环境中主人正在接触的信息
   ✓ "了解了AI安全认证框架"（主人主动讨论的话题）
   ✗ "外面在下雨"（与主人无关）

subject 格式"类别.对象"（如 饮食.辣、装修.进度、工作.公司、行程.出差）
value 是一句有意义的完整中文句。同一主题复用同一 subject。
confidence 0-1，evidence 不超过 30 字。

不合格记忆示例（绝对不要输出）：
✗ "有人提到了超多的情况"（空洞）
✗ "对方表示这边有"（碎片）
✗ "确认了某处地点是基地"（不可理解）
✗ "主人说今天天气不错"（无长期价值）

不确定的不要输出——宁可漏，不可错。
没有记忆时输出空数组 []。
